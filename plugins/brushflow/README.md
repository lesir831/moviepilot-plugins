# 站点刷流

## TOTP fork（5.2.4）

本分支基于本机已安装的 5.2.3 完整源码，保留原作者
`jxxghp, InfinityPacer, Seed680` 及全部任务/历史数据，继续使用 `BrushFlow` ID。

在 MoviePilot 插件市场添加仓库 `https://github.com/lesir831/moviepilot-plugins`，
从该仓库安装或重装“站点刷流”。升级沿用原 `BrushFlow` 配置与历史；切换仓库前建议备份。
要求 MoviePilot `v2.14.6+`。TOTP 必须在各自的 MoviePilot 实例内配置，仓库不提供账号密钥。

在杜比任务的 **高级 → 杜比两步验证 → TOTP 密钥** 输入 Base32 secret 或完整
`otpauth://totp/...` URI（SHA1、30 秒、6 位）。不要填写临时六位验证码。
任务编辑接口只返回“已配置”状态，不返回原密钥；编辑留空保留，勾选清除后删除。
更换任务站点时不继承原站点密钥。密钥保存在 MoviePilot 管理员插件配置中，
不包含在源码、任务详情、运行历史或日志中。

下载处理直接集成在本插件中：

- 只有刷流下载杜比种子时才检查返回结果，没有独立轮询或全局 HTTP 拦截。
- 使用站点当前 Cookie、UA 和代理；认证与下载保持相同 UA。
- 识别真正的两步验证表单后提交一次 TOTP，再访问控制面板确认登录。
- 验证成功回写站点 Cookie、发送站点更新事件，再重试原下载一次。
- 对返回内容做 torrent 解析，HTML 不会交给 qBittorrent/Transmission。
- 同站点两次验证码提交至少间隔 5 分钟；全量登录失效、Cloudflare 挑战及
  其他错误页会明确报告失败，不视为两步验证，也不无限重试。
- qB 返回 `(False, [])` 时立即判定添加失败，不再无效等待种子 Hash。
- 认证失败会记入原刷流运行诊断；此前本轮成功添加的种子记录仍会保存。

无需独立验证插件或额外密钥文件。任务停用时不会发起认证，也不会自动开启任务。
当前自动认证仅适配 HDDolby；其他站点沿用原下载逻辑。

后端测试：在 MoviePilot Python 环境运行
`python -m pytest tests/test_brushflow_site_auth.py tests/test_brushflow_totp.py -q`。
前端：在本插件目录执行 `npm ci && npm run build`。

站点刷流 V5 使用 Vue 模块联邦提供任务工作台。每项任务独立绑定一个站点和一个下载器，并拥有自己的调度周期、选种与删种规则、托管记录、统计和运行诊断。

全局设置支持限制所有任务合计的保种体积、同时下载任务数和总上传下载带宽；任务编辑器中的运行限额仍只约束当前任务。限额留空或设置为 `0` 表示不限制。

全局动态删种会汇总所有启用任务的做种体积。单值阈值（如 `100`）在达到 100 GB 后删到 100 GB；区间阈值（如 `50-100`）在达到 100 GB 后删到 50 GB。任务启用动态删种时，其已完成非 H&R 种子会参加全局兜底淘汰；未启用的任务只会在全局阈值触发后按自身删种条件处理。关闭全局模式时，没有独立动态删种阈值的参与任务会恢复为按条件删除。

任务可启用站点账号分享率控制：插件读取 MoviePilot 最新站点统计，当前分享率达到目标时等待，低于目标时自动恢复新增种子。启用控制但尚无可用统计数据时，任务会等待数据更新。

## 升级兼容

- V5 依赖 MoviePilot `v2.14.6+` 提供的 Vue 联邦宿主能力，旧版宿主会在安装和更新前拒绝该版本。
- 首次加载 V5 时，旧版 `brushsites` 会按站点拆分为独立任务。
- 从 V4 直接升级时，原有运行限额和全局动态删种会迁移到新的全局设置；已升级到 V5 的用户可在全局设置中重新设置合计限额。
- 旧版站点覆盖 JSON 会合并到对应任务中。
- 原有种子、归档和未托管数据会按站点迁移到任务命名空间。
- 已有的全局 `刷流` 标签继续识别；V5 新增任务唯一标签，避免多个任务互相接管。
- V5.0.2 会在插件启动、任务检查和任务删除后清理 qBittorrent 中不再被任何种子使用的 `刷流-*` 标签；仍绑定种子的标签不会被强制移除。
- V5.1.0 新增站点账号分享率目标控制，并限制运行诊断长列表在模块内部滚动。
- V5.1.1 修复 YemaPT 间接下载链接只返回 token、导致刷流任务无法获取种子 Hash 的问题。
- V5.1.2 会在最近的免费促销截止时间即时检查未完成下载，同时保留周期检查兜底，并修正跨时区到期判断。
- V5.2.0 恢复 V4 的全局动态删种，并适配 V5 的多任务、多下载器和任务级托管开关。
- V5.2.1 修复同一下载器共享种子的跨任务保护，并按任务记录实际删除原因。
- V5.2.2 将详情弹窗的滚动限制在右侧工作区，固定顶部标题栏和左侧任务栏，并移除重复失效的配置切换按钮。
- V5.2.3 兼容 qBittorrent 5.2.3，修复动态删种后的未使用标签清理报缺少 `hashes` 参数。

## 前端入口

插件构建产物暴露以下联邦组件：

| 组件 | 用途 |
| --- | --- |
| `AppPage` | 主界面侧栏中的完整刷流工作台 |
| `Page` | 插件详情弹窗 |
| `Config` | 插件配置弹窗 |
| `Dashboard` | 仪表板任务概览 |

侧栏入口由插件的 `get_sidebar_nav()` 注册，可在工作台全局设置中关闭。

## 插件 API

所有接口均使用宿主 Bearer 认证，基础路径为 `/api/v1/plugin/BrushFlow`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/status` | 获取全局状态、任务摘要与可选站点下载器 |
| `POST` | `/settings` | 更新插件与侧栏入口开关 |
| `POST` | `/tasks` | 创建任务 |
| `GET` / `PUT` / `DELETE` | `/tasks/{task_id}` | 查询、更新或删除任务 |
| `POST` | `/tasks/{task_id}/state` | 启用或暂停任务 |
| `POST` | `/tasks/{task_id}/run` | 立即执行刷流刷新 |
| `POST` | `/tasks/{task_id}/check` | 立即执行种子检查 |
| `POST` | `/tasks/{task_id}/clear` | 清除当前任务的独立数据 |

## 构建

在本目录安装依赖后执行 `yarn build`，产物生成到 `dist/assets`，由插件后端的 Vue 渲染模式加载。
